🎉 Test Web App

This is a sample web app for testing the Web App Reader extension overlay!

Testing Instructions:

  1. Load the Web App Reader extension in your browser
  2. Navigate to any webpage (e.g., https://www.google.com)
  3. Right-click the extension icon and select "Options"
  4. Add this test app URL or another web app URL
  5. Go back to your webpage and click the extension icon
  6. Click on a saved app to open it in an overlay
  7. Try dragging the overlay by its header
  8. Try resizing by dragging the bottom-right corner
  9. Test the minimize, maximize, and close buttons
